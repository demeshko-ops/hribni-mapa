# 🍄 Грибна мапа ČR

Інтерактивна мапа ймовірності росту грибів у Чехії з власними грибними місцями.
Оновлюється автоматично щоранку через GitHub Actions і публікується на GitHub Pages.

## Як рахується
Для сітки ~11×11 км (700 точок) береться погода з [Open-Meteo](https://open-meteo.com/) (CC BY 4.0):
- **API30**: індекс вологості ґрунту, сума опадів за 30 днів із коефіцієнтом згасання 0,93 (метод, який описує ČHMÚ);
- **T7**: середня температура за 7 днів.

Індекс 0–100 = вологість (8 мм → 0, 35 мм → 1) × температурний коефіцієнт (оптимум 10–20 °C).
Шар «Через 3 дні» рахується з прогнозу. Це власне наближення, а не офіційна мапа ČHMÚ.

## Місця
- **Instagram**: відкриті, у `site/data/spots.json`.
- **Особисті**: додаються кнопкою «+» на мапі (координати, посилання Google Maps / Mapy.cz, «де я зараз» або тап на мапі) з приміткою і категорією.
  Зберігаються у `site/data/private.enc.json`, зашифровані AES-256-GCM паролем (PBKDF2, 250k ітерацій).
  Без пароля їх прочитати неможливо, і без пароля їх не відновити. Резервна копія: ⚙ → Експорт.
- Для збереження з пристрою потрібен fine-grained GitHub-токен лише на цей репозиторій (Contents: Read and write).

## Ручне оновлення
Actions → *Update mushroom map* → *Run workflow*.
