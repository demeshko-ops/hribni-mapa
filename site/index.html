Доступ для збереження місць

Щоб додавати місця з цього пристрою, потрібен GitHub-токен лише для репозиторію hribni-mapa. Він зберігається тільки на цьому пристрої.

1. Створити токен → Repository access: Only select repositories → hribni-mapa
2. Permissions → Repository → Contents: Read and write
3. Generate → скопіюйте сюди.

Особисті місця

Як рахується шанс росту

Щоранку для квадратів ~11×11 км рахуються вологість ґрунту за 30 днів (API30, як у методиці ČHMÚ) і середня температура за 7 днів (оптимум 10–20 °C). Це власна наближена модель, не офіційна мапа ČHMÚ. Порівняти: ČHMÚ, Mykoindex.
